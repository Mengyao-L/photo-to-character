# 表情、动作与动画资产

## 表情或动作角色表

以同一角色档案和标准图生成指定姿态，统一线宽、色板、头身比例、画面尺度和留白。按用户数量安排清楚的网格；文字标签仅在要求时添加。检查每格是否出现花纹换边、眼距变化和肢体粘连。

示例动作：开心、委屈、疑惑、困困、探头、蹭蹭。动作是可选菜单，不是默认必须生成的整套内容。

## 动画准备

用户需要拆层时，建议的部件名称如下。L/R 均指角色自身左右；遮挡关系按具体视角处理。

Head / Body / Ear_L / Ear_R / Eye_L / Eye_R / Nose_Mouth / Paw_FL / Paw_FR / Paw_BL / Paw_BR / Tail

眨眼可用睁眼、半闭、闭眼关键状态；摇尾保持根部位置稳定；呼吸保持轮廓与花纹同步微动。用户要求可播放动画时才制作帧时序、循环和导出，并检查实际播放。

只有实际分离、补齐被遮挡区域并检查过的图层才能称为分层资产。图层命名建议不等于已完成分层。只有静态姿态图时称为“动画关键姿势/原型”，不要声称可直接作为成品动画使用。

若输出独立帧，统一画布、角色基准位置、缩放、背景和命名，并确认各帧没有意外裁切。用户没有指定动画软件时，无需强行引入绑定系统或固定精灵图尺寸。
